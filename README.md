Entry for the make.fun bounty "One Line, Big Laugh": a Python program that writes one funny line (133 characters, inside the 1–200 gate) to /output/entry.txt. The line is checked before writing — it must be a single non-empty line within the cap — and the written file is read back and verified to match exactly.

## Run it

```sh
python3 main.py
```
